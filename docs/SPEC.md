# ClinicBook Specification

This document is the working product and architecture specification for ClinicBook.

The canonical, agent-oriented copy of the full specification is maintained in the repository root: [`../AGENTS.md`](../AGENTS.md).

## Scope

ClinicBook is a multi-clinic appointment booking platform supporting patients, providers, clinic staff, and administrators. Core capabilities include discovery and scheduling, booking with holds and payments, notifications/reminders, secure medical records, reporting, and an AI-ready extension architecture.

## Implementation Phases

1. Foundation
2. Identity & security
3. Provider & scheduling management
4. Slot engine
5. Booking flow
6. Payments
7. Jobs & notifications
8. Medical notes & files
9. Admin dashboard & reports
10. Frontend
11. Hardening
12. Production
13. AI integration

Refer to [`../AGENTS.md`](../AGENTS.md) for complete requirements, constraints, and the definition of done for each phase.
