ClinicBook

A production-grade, multi-clinic appointment booking platform. This GitHub Pages site is a static placeholder; the full web application will be implemented in Phase 10.

Patients

Find providers, view availability, book, pay, and receive reminders.

Providers & Clinics

Manage schedules, services, and appointments with policy-driven workflows.

Platform

Secure-by-default design, auditing, observability, and AI-ready extension points.

Architecture & Stack

ASP.NET Core (.NET 8), Clean Architecture + CQRS (MediatR), EF Core + PostgreSQL, Redis, Serilog/OpenTelemetry, React + TypeScript (planned).

  • Backend API, health checks, and core building blocks are scaffolded in Phase 1.
  • Upcoming: identity & security (HttpOnly cookie auth), scheduling/slots, booking, payments, notifications, and more.
